  • Anoptic Engine

    Since 2022

    A real-time world simulator and reinforcement-learning environment, for large-scale agent simulations that general-purpose engines handle poorly. It runs headless on servers, with deterministic replay for reproducible episodes, and its core is lock-free and data-oriented: every system talks through a message-passing event bus, over scoped arena allocators with hugepage backing, so many instances step fast side by side. Written in C23, with C++26 static reflection specializing each module’s interface at compile time, it runs alike on Linux, Windows and Apple Silicon, with a Vulkan mesh-shader renderer to watch it by, reproducible under Nix and tested under ASan, TSan and UBSan.

  • anolangあの

    Since 2026

    Anoptic Engine’s scripting language and entity-component layer. Rules select entities by description instead of looping over objects, drawing on SQL, kdb+/q, APL and Datalog, and each statement compiles to a few vectorized column operations over the engine’s structure-of-arrays store, so observations and rewards over thousands of entities stay cheap. The toolchain is about 36k lines of Rust, compiling to BQN’s array runtime, with joins, grouped aggregation, referential integrity and conflict-free batched writes.
