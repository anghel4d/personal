# anghel4d.com

The personal site of Matei Anghel: a single static page over a live three.js lagoon, with physically based caustics and a day and night mode.

The water is adapted from [Clearwater](https://github.com/Aureliengmz/clearwater) by Aurélien at Lumaris, under the MIT license (`licenses/clearwater.txt`).

Open `index.html` through any static server (`python3 -m http.server`) to preview it. See `CLAUDE.md` for how it is built.
