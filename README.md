# anghel4d.com

The personal site of Matei Anghel: a single static page over a live three.js lagoon, with physically based caustics and a day and night mode.

The water follows [CAUSTIC//VOLUME](https://github.com/ScottieFox/caustic-volume) by Scottie, with parts of [Clearwater](https://github.com/Aureliengmz/clearwater) by Aurélien at Lumaris. Tone mapping is the GT7 operator from Polyphony Digital's [SIGGRAPH 2025 course talk](https://blog.selfshadow.com/publications/s2025-shading-course/), ported from their sample implementation. All three are under the MIT license (`licenses/`).

Open `index.html` through any static server (`python3 -m http.server`) to preview it. See `CLAUDE.md` for how it is built.
